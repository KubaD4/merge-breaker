Merge Breaker

A real run of the full pipeline on tiny-shop-api, a sample repo whose new dependency hides a credential-stealing install script. Only the merge that triggers it is simulated.

Scanning another repository executes its code on this server and uses paid inference credits, so on this public demo it requires the owner's run token.

To see the complete pipeline, use Run on demo repo above. It is not a recording: every stage runs live.

Runs

    Merge Breaker tests a repository after each merge to main. The code is cloned into isolated containers, dependency install scripts are executed offline with decoy credentials, exported functions are fuzzed, and an agent writes and runs targeted attacks. A finding is reported only if an execution reproduced it.

    1. FetchClone, install with scripts disabled
    2. DetonateInstall scripts run offline under trace
    3. FuzzHostile inputs into every export
    4. Injection scanRules and a Vultr safety model vote on hidden instructions
    5. AttackAI writes exploits, sandbox runs them
    6. ReportVerdict decided by rules, never by a model
